# Upstream attribution

Hacksfield is a modified distribution of [nickvasilescu/parallax](https://github.com/nickvasilescu/parallax).

- Upstream baseline: `f1bad63` (full commit identity remains in Git history).
- Original author/copyright: Nick Vasilescu, 2026.
- Licence: MIT. The original [LICENSE](LICENSE) is retained verbatim.
- Fork maintained by [EAIC](https://github.com/enterprise-ai-consulting).

The fork adds direct BytePlus/Decart adapters, membership-free defaults, a shared
provider spending budget, private credential settings and storage, a subscription
assistant bridge, additional model/tool recipes, private MCP downloads, offline
regression tests, and Hacksfield branding.

Upstream sample media, seed content and historical documentation screenshots are
retained as reference material; they are not EAIC's private media library. Internal
`PARALLAX_*` configuration names, storage prefixes and some helper filenames remain
for compatibility. This is not a fork of or an integration that bypasses Higgsfield.
